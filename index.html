Integrasi Backend Google Sheets (Apps Script)

Aplikasi berjalan dengan arsitektur Offline-First. Semua transaksi instan 0ms tersimpan di perangkat dan otomatis disinkronkan ke Google Sheets Anda.

Kode Backend Siap Pakai (Code.gs)

Dilengkapi LockService anti-bentrok stok, validasi token, dan auto-create 5 tab database.

  1. Buka Google Sheets baru → klik menu Ekstensi (Extensions) > Apps Script.
  2. Hapus semua kode bawaan, lalu tempel kode Code.gs di bawah ini.
  3. Klik Deploy > New deployment > Web app. Set Execute as: Me dan Who has access: Anyone.
  4. Salin URL Web App yang muncul dan tempelkan pada kolom konfigurasi di atas.
